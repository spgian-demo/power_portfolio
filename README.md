# Power Portfolio

Course 121: Power Portfolio Positions and Cash Flows.
Lecture 6.1: Saving Portfolio Inputs to CSV.

## CSV

The existing main.py generates the seed-42 sample, calculates and prints the
same full-day report, then saves the SAME input records to:

    data/portfolio_inputs_2026-09-01.csv

The default data folder is beside main.py, not inside .venv. Its path does not
depend on the shell's current directory. main(output_directory=...) may instead
be called with a pathlib.Path, as the existing report test does with tmp_path.
The program creates missing parent directories. Each successful export replaces
the CSV at the chosen path. It does NOT append 48 more records on each run.
Save a separate copy before editing a CSV that you want to keep.

## CSV contents and assumptions

The UTF-8 comma-separated text file contains one header and 48 data records.
Each record holds:

| Column | Meaning |
| --- | --- |
| delivery_date | The illustrative date, written as YYYY-MM-DD. |
| settlement_period | Integer identifier 1 through 48 for this sample day. |
| wind_mwh | Total electricity generated by the wind farm in that period. |
| solar_mwh | Total electricity generated by the solar PV farm in that period. |
| demand_mwh | Combined electricity consumption of the company's customers. |
| price_gbp_per_mwh | Assumed wholesale price in GBP/MWh for that period. |

The exporter repeats the date on each row, preserves record order and applies
no further numerical rounding. CSV stores text representations of values,
not the original Python numeric types, functions or objects. Python's reader
will need explicit conversions in the next lesson.

This saves INPUTS, not net positions, calculated purchases/sales or cash flows.
It is not an Excel workbook or database. No formatting or formulas are added.

The baseline market cash flow is still -437.28 GBP, rounded for display.
That figure is not the company's complete profit or loss.
